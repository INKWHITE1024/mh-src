# Examples

`demo_splits/` contains single-participant split files used to generate inspectable
example outputs. The raw samples themselves are covered by the datasets' access
agreements and are **not redistributed** with this repository.

These splits are **not** official train splits and their reference statistics must not be
used for model training, validation, testing, or reported experiments. Production
references must be fitted from each dataset's complete official training split.

`rethinking/` contains synthetic contract examples for the two-pass workflow and the
query-grounded atomic retrieval interface. They are schema examples, not predictions.
